# Documentation

The documentation website is built with [Fumadocs](https://fumadocs.dev) (Next.js) and deployed as a static site to https://shopify.github.io/react-native-skia.

## Development

```sh
yarn dev
```

The site is served under the same base path as in production: http://localhost:3000/react-native-skia.

## Writing docs

- Pages live in `content/docs` and their path is their URL (`content/docs/shapes/path.mdx` is `/docs/shapes/path`). Folders wrapped in parentheses, like `(images)`, group pages in the sidebar without changing their URL.
- The sidebar order is defined in the `meta.json` files. Use the `sidebarLabel` frontmatter for a shorter sidebar entry than the page title.
- Code blocks marked with `twoslash` (` ```tsx twoslash `) are type-checked against the sources of `@shopify/react-native-skia` when building the site: a type error fails the build. Readers get type information when hovering the code.
- Reference images generated by the test suite (`docPath()` in `packages/skia`) are in `public/img` and are displayed with `<Img src="/img/..." width={256} height={256} />`.

## Live examples

Examples can run in the browser using the web version of React Native Skia (CanvasKit):

1. Add a component in `src/examples` (with a default export) and register it in `src/examples/index.ts`.
2. In the page, show its source and render it:

```mdx
<include cwd meta="twoslash">src/examples/HelloWorld.tsx</include>

<LiveExample name="hello-world" />
```

The code displayed on the page is the code that runs, and it is type-checked by both `yarn tsc` and the build.

## Build

```sh
yarn build
```

This generates the static website in the `out` directory.
